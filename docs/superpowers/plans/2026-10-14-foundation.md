# LADCMS Foundation (волна 0 + скелет core) — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Поднять монорепо `ladcms/ladcms` с приложением `app/` на react-starter-kit в Docker (Sail), пакетом `packages/core` с контрактом модуля (`ModuleServiceProvider`, `ModuleRegistry`, интерфейсы `Has*`), командами `ladcms:install|update|uninstall`, загрузкой React-страниц модулей и CI/split-воркфлоу — так, чтобы тестовый модуль ставился и рендерил страницу.

**Architecture:** Монорепо: `app/` (Laravel 13 + Inertia 3 + React 19, starter kit) подключает `packages/*` через composer `path`-репозитории (symlink). `core` — Laravel-пакет на `spatie/laravel-package-tools`; каждый модуль (включая сам `core`) наследует `ModuleServiceProvider`, который грузит конфиг/миграции/роуты/переводы и регистрирует модуль в `ModuleRegistry`. React-страницы модулей резолвятся по имени `module::Path` через `import.meta.glob` по `vendor/ladcms/*/resources/js/pages/**` (symlink → `packages/*`). Тесты пакетов — Pest 5 + Testbench из корня монорепо; тесты приложения — в `app/`.

**Tech Stack:** PHP 8.4 (Sail runtime), Laravel 13, Inertia 3 (`inertiajs/inertia-laravel` ^3, `@inertiajs/react` ^3), React 19, TypeScript, Vite 8 (`vite-plus`), Tailwind 4, Pest 5, orchestra/testbench ^11, spatie/laravel-package-tools, spatie/laravel-permission ^8, spatie/laravel-settings ^3, Laravel Sail, Laravel Boost, GitHub Actions + `danharrin/monorepo-split-github-action`.

**Spec:** `docs/superpowers/specs/2026-10-14-ladcms-foundation-and-core-design.md` (разделы 2, 3, 4, 7, 8).

## Global Constraints

- PHP минимум `^8.4` во всех `composer.json` пакетов; Laravel `^13.0`; `php: ^8.4` в Sail runtime (`--php=8.4`).
- Все пакеты: namespace `Ladcms\<Package>\`, имя composer `ladcms/<package>`, лицензия MIT.
- Бизнес-логика только в `src/Actions/*` с одним публичным методом `handle()`; каждый Action покрыт unit-тестом без HTTP.
- Имена Inertia-страниц модулей: `<module>::<Path/To/Page>`; страницы `app/` — без префикса.
- Модули не имеют своего `package.json`; npm-зависимости объявляются в `npmDependencies()` провайдера.
- Команды внутри контейнера: `cd app && vendor/bin/sail <artisan|composer|npm|pest> …`. Тесты пакетов — из корня: `vendor/bin/pest`.
- Коммит после каждой задачи, сообщения на английском в стиле Conventional Commits (`feat:`, `chore:`, `test:`), в конце `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.
- Никаких правок в `vendor/`. `.superpowers/`, `app/.mcp.json`, `app/boost.json`, `app/CLAUDE.md` — в `.gitignore`.

## Review Focus

1. Модуль с несовместимым `coreVersion()` (например `^9.0`) не должен ронять приложение: провайдер не бутится, `ModuleRegistry::failures()` содержит причину, `/` отдаёт 200. — тест в Task 5.
2. Модуль, чья `dependencies()` содержит неустановленный модуль, — то же поведение; порядок регистрации провайдеров не должен влиять (зависимость может бутиться позже). — тест в Task 5 (проверка выполняется отложенно, после boot всех провайдеров).
3. Повторный запуск `ladcms:install dummy` не создаёт дублей permissions, не дублирует npm-зависимости в `package.json` и не падает на уже применённых миграциях. — тест в Task 8.
4. `ladcms:install unknown` для несуществующего модуля — осмысленная ошибка и код выхода 1, без частичных побочных эффектов. — тест в Task 7.
5. Имя страницы с `::`, у которой нет файла (`dummy::Missing`), — `Inertia::render` бросает `ComponentNotFoundException` при `ensure_pages_exist=true`, а не 500 без объяснения. — тест в Task 10.

```php
<?php

namespace Ladcms\Core\Module;

use Composer\Semver\Semver;
use Illuminate\Support\Collection;

class ModuleRegistry
{
    /** @var array<string, ModuleServiceProvider> */
    private array $modules = [];

    /** @var array<string, ModuleFailure> */
    private array $failures = [];

    private bool $validated = false;

    public function __construct(private readonly string $coreVersion) {}

    public function register(ModuleServiceProvider $module): void
    {
        $this->modules[$module->name()] = $module;
        $this->validated = false;
    }

    /**
     * Проверяет версии и зависимости. Вызывается после boot всех провайдеров,
     * чтобы порядок регистрации не влиял на результат.
     */
    public function validate(): void
    {
        if ($this->validated) {
            return;
        }

        foreach ($this->modules as $name => $module) {
            if ($name === 'core') {
                continue;
            }

            if (! Semver::satisfies($this->coreVersion, $module->coreVersion())) {
                $this->fail($name, "requires core {$module->coreVersion()}, installed {$this->coreVersion}");
            }
        }

        // Зависимости проверяем отдельным проходом, когда известно, кто уже отвалился.
        do {
            $changed = false;
            foreach ($this->modules as $name => $module) {
                foreach ($module->dependencies() as $dependency) {
                    if (! isset($this->modules[$dependency])) {
                        $this->fail($name, "requires module [{$dependency}] which is not installed or failed");
                        $changed = true;
                        break;
                    }
                }
            }
        } while ($changed);

        $this->validated = true;
    }

    private function fail(string $name, string $reason): void
    {
        unset($this->modules[$name]);
        $this->failures[$name] = new ModuleFailure($name, $reason);
        logger()->warning("LADCMS module [{$name}] disabled: {$reason}");
    }

    /** @return Collection<string, ModuleServiceProvider> */
    public function all(): Collection
    {
        $this->validate();

        return collect($this->modules);
    }

    public function has(string $name): bool
    {
        return $this->all()->has($name);
    }

    public function get(string $name): ?ModuleServiceProvider
    {
        return $this->all()->get($name);
    }

    /** @return list<string> */
    public function names(): array
    {
        return $this->all()->keys()->values()->all();
    }

    /** @return array<string, ModuleFailure> */
    public function failures(): array
    {
        $this->validate();

        return $this->failures;
    }

    /**
     * @template T of object
     *
     * @param  class-string<T>  $interface
     * @return Collection<string, ModuleServiceProvider&T>
     */
    public function implementing(string $interface): Collection
    {
        return $this->all()->filter(fn (ModuleServiceProvider $m) => $m instanceof $interface);
    }
}
```

```php
abstract class ModuleServiceProvider extends PackageServiceProvider implements ModuleInterface
{
    public function coreVersion(): string
    {
        return '*';
    }

    public function dependencies(): array
    {
        return [];
    }

    public function optionalDependencies(): array
    {
        return [];
    }

    public function npmDependencies(): array
    {
        return [];
    }

    public function install(): void {}

    public function uninstall(): void {}

    /** Абсолютный путь внутри пакета модуля. */
    public function modulePath(string $relative = ''): string
    {
        return rtrim($this->package->basePath('/../'), '/').($relative !== '' ? '/'.ltrim($relative, '/') : '');
    }

    public function configurePackage(Package $package): void
    {
        $package->name($this->name());

        $base = $package->basePath('/../');

        if (is_file("{$base}/config/{$this->name()}.php")) {
            $package->hasConfigFile($this->name());
        }
        if (is_dir("{$base}/database/migrations")) {
            $package->discoversMigrations()->runsMigrations();
        }
        if (is_dir("{$base}/lang")) {
            $package->hasTranslations();
        }
        if (is_dir("{$base}/resources/views")) {
            $package->hasViews();
        }

        $this->configureModule($package);
    }

    /** Точка расширения для модуля (команды, доп. ассеты). */
    protected function configureModule(Package $package): void {}

    public function packageRegistered(): void
    {
        $this->app->make(ModuleRegistry::class)->register($this);
    }

    public function packageBooted(): void
    {
        $this->loadModuleRoutes();
    }

    protected function loadModuleRoutes(): void
    {
        $name = $this->name();
        $routes = $this->modulePath('routes');

        if (is_file("{$routes}/web.php")) {
            Route::middleware('web')->group("{$routes}/web.php");
        }
        if (is_file("{$routes}/admin.php")) {
            Route::middleware(['web', 'auth', 'admin'])
                ->prefix("admin/{$name}")
                ->name("admin.{$name}.")
                ->group("{$routes}/admin.php");
        }
        if (is_file("{$routes}/api.php")) {
            Route::middleware(['api', 'auth:sanctum'])
                ->prefix("api/{$name}")
                ->name("api.{$name}.")
                ->group("{$routes}/api.php");
        }
    }
}
```

```php
namespace Ladcms\Core\Actions\Modules;

class SyncNpmDependencies
{
    /** @return array<string,string> добавленные зависимости */
    public function handle(array $dependencies, string $packageJsonPath): array
    {
        if ($dependencies === [] || ! is_file($packageJsonPath)) {
            return [];
        }

        $json = json_decode(file_get_contents($packageJsonPath), true, flags: JSON_THROW_ON_ERROR);
        $existing = $json['dependencies'] ?? [];
        $added = array_diff_key($dependencies, $existing);

        if ($added === []) {
            return [];
        }

        $json['dependencies'] = $existing + $added;
        ksort($json['dependencies']);
        file_put_contents($packageJsonPath, json_encode($json, JSON_PRETTY_PRINT | JSON_UNESCAPED_SLASHES)."\n");

        return $added;
    }
}
```

`UninstallModule.php`:
```php
<?php

namespace Ladcms\Core\Actions\Modules;

use Illuminate\Support\Facades\Artisan;
use Ladcms\Core\Models\Module;
use Ladcms\Core\Module\Contracts\HasPermissions;
use Ladcms\Core\Module\ModuleNotFoundException;
use Ladcms\Core\Module\ModuleRegistry;
use Spatie\Permission\Models\Permission;

class UninstallModule
{
    public function __construct(private readonly ModuleRegistry $registry) {}

    public function handle(string $name, bool $rollbackMigrations = false): void
    {
        $module = $this->registry->get($name) ?? throw new ModuleNotFoundException($name);

        $module->uninstall();

        if ($rollbackMigrations) {
            $path = $module->modulePath('database/migrations');
            foreach (array_reverse(glob("{$path}/*.php") ?: []) as $file) {
                $migration = require $file;
                $migration->down();
                \Illuminate\Support\Facades\DB::table('migrations')->where('migration', pathinfo($file, PATHINFO_FILENAME))->delete();
            }
        }

        if ($module instanceof HasPermissions) {
            Permission::whereIn('name', array_keys($module->permissions()))->delete();
        }

        Module::where('name', $name)->delete();
    }
}
```

```php
<?php

namespace Ladcms\Core\Inertia;

use InvalidArgumentException;
use Ladcms\Core\Module\ModuleRegistry;

class ModulePageFinder
{
    public function __construct(
        private readonly object $inner,
        private readonly ModuleRegistry $registry,
        private readonly array $extensions = ['tsx', 'jsx', 'ts', 'js'],
    ) {}

    public function find(string $name): string
    {
        if (! str_contains($name, '::')) {
            return $this->inner->find($name);
        }

        [$module, $page] = explode('::', $name, 2);
        $provider = $this->registry->get($module)
            ?? throw new InvalidArgumentException("Inertia page [{$name}]: module [{$module}] is not registered.");

        foreach ($this->extensions as $ext) {
            $file = $provider->modulePath("resources/js/pages/{$page}.{$ext}");
            if (is_file($file)) {
                return $file;
            }
        }

        throw new InvalidArgumentException("Inertia page [{$name}] not found in module [{$module}].");
    }

    public function __call(string $method, array $args): mixed
    {
        return $this->inner->{$method}(...$args);
    }
}
```

```ts
    name: string,
    appPages: Record<string, PageLoader>,
    modulePages: Record<string, PageLoader>,

}
```

- [ ] **Step 2: Скрипт переписывания `app/composer.json` для сплита**

`.github/split/rewrite-app-composer.php`:
```php
<?php
// Usage: php rewrite-app-composer.php app/composer.json 1.2.0
[$_, $file, $version] = $argv;
$json = json_decode(file_get_contents($file), true, flags: JSON_THROW_ON_ERROR);
unset($json['repositories']);
[$major, $minor] = explode('.', ltrim($version, 'v'));
foreach ($json['require'] as $name => $constraint) {
    if (str_starts_with($name, 'ladcms/')) {
        $json['require'][$name] = "^{$major}.{$minor}";
    }
}
file_put_contents($file, json_encode($json, JSON_PRETTY_PRINT | JSON_UNESCAPED_SLASHES)."\n");
```

- [ ] **Step 3: Split**

`.github/workflows/split.yml`:
```yaml
name: Split packages

on:
  push:
    branches: [main]
    tags: ['v*']

env:
  GITHUB_TOKEN: ${{ secrets.SPLIT_TOKEN }}

jobs:
  split:
    runs-on: ubuntu-latest
    strategy:
      fail-fast: false
      matrix:
        package:
          - { local_path: packages/core, repo: core }
          - { local_path: app, repo: app }
    steps:
      - uses: actions/checkout@v4

      - name: Rewrite app composer.json for standalone install
        if: matrix.package.repo == 'app'
        run: php .github/split/rewrite-app-composer.php app/composer.json "${GITHUB_REF_NAME#v}"

      - if: "!startsWith(github.ref, 'refs/tags/')"
        uses: danharrin/monorepo-split-github-action@v2.4.0
        with:
          package_directory: ${{ matrix.package.local_path }}
          repository_organization: ladcms
          repository_name: ${{ matrix.package.repo }}
          user_name: ladcms-bot
          user_email: bot@ladcms.dev

      - if: startsWith(github.ref, 'refs/tags/')
        uses: danharrin/monorepo-split-github-action@v2.4.0
        with:
          tag: ${GITHUB_REF#refs/tags/}
          package_directory: ${{ matrix.package.local_path }}
          repository_organization: ladcms
          repository_name: ${{ matrix.package.repo }}
          user_name: ladcms-bot
          user_email: bot@ladcms.dev
```
На ветке `main` (не тег) `GITHUB_REF_NAME` = `main` → скрипт получит `main` и упадёт на `explode`. Поэтому добавить в начало скрипта: `if (! preg_match('/^\d+\.\d+/', ltrim($version, 'v'))) { $version = '0.1.0'; }`.
